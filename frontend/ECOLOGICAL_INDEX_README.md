# 生态环境指数计算系统

## 系统概述

这是一个基于Vue 3开发的生态环境指数计算系统，采用苹果风格设计，提供直观、美观的用户界面。系统支持两种主要的生态环境指数计算：

### 1. 生态环境结构指数
- **破碎度指数**：衡量景观破碎化程度（单位：/km²）
- **内聚力指数**：评估生态系统连接度（单位：%）
- **多样性指数**：计算生态多样性（单位：Shannon指数）
- **脆弱度指数**：评估生态系统脆弱性（单位：%）

### 2. 生态环境胁迫指数
- **土壤侵蚀指数**：评估土壤侵蚀程度（单位：t/ha·a）
- **未利用地面积比例**：计算未利用地占比（单位：%）
- **耕地面积比例**：计算耕地占比（单位：%）
- **建设用地面积比例**：计算建设用地占比（单位：%）
- **土地退化指数**：评估土地退化程度（单位：%）

## 使用方法

### 1. 访问系统
在浏览器中访问 `/ecological-index` 路径，或通过主页面"生态环境指数计算"功能进入。

### 2. 选择计算类型
- 点击"生态环境结构指数"或"生态环境胁迫指数"
- 系统会显示相应的参数输入界面

### 3. 输入参数
根据实际情况输入各项指标数据：
- 所有字段都是必填的
- 支持小数点输入
- 单位已在标签中明确标注

### 4. 开始计算
- 点击"开始计算"按钮
- 系统会显示计算进度
- 计算完成后显示结果

### 5. 查看结果
- **单项指标结果**：显示各指标的具体数值和状态评估
- **综合评估**：提供0-100分的综合评分和总体评价
- **建议措施**：根据计算结果自动生成改进建议

## 评分标准

### 生态环境结构指数评分规则
- **破碎度指数**：越低越好（权重25%）
  - < 0.5：25分
  - < 1.0：20分
  - < 2.0：15分
  - < 3.0：10分
  - ≥ 3.0：5分

- **内聚力指数**：越高越好（权重25%）
  - > 80%：25分
  - > 60%：20分
  - > 40%：15分
  - > 20%：10分
  - ≤ 20%：5分

- **多样性指数**：适中最好（权重25%）
  - 1.5-2.5：25分
  - 1.0-3.0：20分
  - 0.5-3.5：15分
  - 0.0-4.0：10分
  - 其他：5分

- **脆弱度指数**：越低越好（权重25%）
  - < 20%：25分
  - < 40%：20分
  - < 60%：15分
  - < 80%：10分
  - ≥ 80%：5分

### 生态环境胁迫指数评分规则
- **土壤侵蚀指数**：越低越好（权重20%）
  - < 5 t/ha·a：20分
  - < 10 t/ha·a：16分
  - < 20 t/ha·a：12分
  - < 50 t/ha·a：8分
  - ≥ 50 t/ha·a：4分

- **未利用地比例**：适中最好（权重20%）
  - 5-15%：20分
  - 2-20%：16分
  - 0-25%：12分
  - 0-30%：8分
  - 其他：4分

- **耕地面积比例**：适中最好（权重20%）
  - 20-40%：20分
  - 15-45%：16分
  - 10-50%：12分
  - 5-55%：8分
  - 其他：4分

- **建设用地比例**：越低越好（权重20%）
  - < 10%：20分
  - < 20%：16分
  - < 30%：12分
  - < 40%：8分
  - ≥ 40%：4分

- **土地退化指数**：越低越好（权重20%）
  - < 10%：20分
  - < 20%：16分
  - < 30%：12分
  - < 40%：8分
  - ≥ 40%：4分

## 综合评估标准

- **80-100分**：生态环境优秀
- **60-79分**：生态环境良好
- **40-59分**：生态环境一般
- **20-39分**：生态环境较差
- **0-19分**：生态环境严重
