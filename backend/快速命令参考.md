# 快速命令参考

## 一、当前启动方式

### 1. 一键启动前后端

在项目根目录执行：

```powershell
.\start_dev.ps1
```

说明：

- 前端固定地址：`http://localhost:3000`
- 后端固定地址：`http://127.0.0.1:8000`
- 若端口已被占用，脚本会直接提示，不会自动漂移到其他端口

---

### 2. 单独启动后端

在项目根目录执行：

```powershell
cd backend
.\start_dev.ps1
```

当前后端启动脚本优先使用：

```text
C:\Users\74749\miniforge3\envs\tianshui-gis\python.exe
```

后端实际运行地址：

```text
http://127.0.0.1:8000
```

---

### 3. 单独启动前端

在项目根目录执行：

```powershell
cd frontend
npm run dev -- --host 127.0.0.1 --port 3000
```

前端实际运行地址：

```text
http://localhost:3000
```

## 七、常见问题

### 1. 前端打不开

先确认：

- `frontend/node_modules` 是否存在
- `3000` 端口是否被其他程序占用

### 2. 后端打不开

先确认：

- GIS 环境是否存在：`C:\Users\74749\miniforge3\envs\tianshui-gis\python.exe`
- `8000` 端口是否被占用

### 3. 上传文件后结果不显示

建议依次检查：

- 当前文件是否适用于对应分析模块
- GeoServer 是否正常运行
- 后端日志是否有报错
- 当前任务是否已完成

### 4. 气候栅格无法自动识别变量

若文件名只有年份，如 `2023年.tif`，系统可能无法自动判断是温度、降水、湿度还是风速。

这时需要在前端手动选择变量后再开始分析。

## 八、建议使用顺序

推荐平时这样启动和使用：

1. 在项目根目录执行 `.\start_dev.ps1`
2. 打开前端：`http://localhost:3000`
3. 管理员先登录
4. 如需管理用户，先进入“用户管理”
5. 再按模块进入遥感、生态指数、气候监测或叠加分析页面
