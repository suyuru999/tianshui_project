# PostgreSQL 快速命令参考

## 🎯 一键迁移命令

```bash
# === 最简单的方式 ===
# 1. 安装依赖
pip install psycopg2-binary python-dotenv

# 2. 运行自动迁移脚本（推荐）
python migrate_to_postgresql.py
# 脚本会引导你完成所有配置

# 3. 启动服务
python manage.py runserver --settings=tianshuipy.settings_postgresql
```

## 📋 PostgreSQL 基本命令

### Windows 启动/停止服务

```bash
# 启动 PostgreSQL 服务
net start postgresql-x64-15

# 停止服务
net stop postgresql-x64-15

# 查看服务状态
sc query postgresql-x64-15
```

### 连接数据库

```bash
# 方式1: 使用 psql（推荐）
psql -U postgres -d tianshuipy

# 方式2: 通过 Django
python manage.py dbshell --settings=tianshuipy.settings_postgresql
```

### 常用 SQL 命令

```sql
-- 列出所有数据库
\l

-- 连接到数据库
\c tianshuipy

-- 列出所有表
\dt

-- 查看表结构
\d users_user
\d remote_sensing_images

-- 查看表数据
SELECT * FROM users_user LIMIT 5;
SELECT COUNT(*) FROM remote_sensing_images;

-- 退出
\q
```

## 🔧 Django 管理命令

### 数据库迁移

```bash
# 使用 PostgreSQL 配置
SET DJANGO_SETTINGS_MODULE=tianshuipy.settings_postgresql

# 或在每个命令后添加
--settings=tianshuipy.settings_postgresql

# 创建迁移文件
python manage.py makemigrations

# 查看迁移状态
python manage.py showmigrations

# 执行迁移
python manage.py migrate

# 回退迁移（慎用）
python manage.py migrate environment 0013
```

### 数据导入导出

```bash
# === 从 SQLite 导出数据 ===
python manage.py dumpdata \
    --settings=tianshuipy.settings_dev \
    --natural-foreign \
    --indent 2 \
    --exclude contenttypes \
    --exclude auth.Permission \
    --output=backup.json

# === 导入到 PostgreSQL ===
python manage.py loaddata backup.json \
    --settings=tianshuipy.settings_postgresql

# === 仅导出特定应用 ===
python manage.py dumpdata environment \
    --settings=tianshuipy.settings_dev \
    --output=environment_data.json

# === 清空数据库（危险！）===
python manage.py flush --settings=tianshuipy.settings_postgresql
```

### 用户管理

```bash
# 创建超级用户
python manage.py createsuperuser \
    --settings=tianshuipy.settings_postgresql

# 修改用户密码
python manage.py changepassword admin \
    --settings=tianshuipy.settings_postgresql
```

### 查看数据库状态

```sql
-- 当前数据库大小
SELECT pg_size_pretty(pg_database_size('tianshuipy'));

-- 所有表大小
SELECT 
    schemaname,
    tablename,
    pg_size_pretty(pg_total_relation_size(schemaname||'.'||tablename)) AS size
FROM pg_tables
WHERE schemaname = 'public'
ORDER BY pg_total_relation_size(schemaname||'.'||tablename) DESC;

-- 活动连接数
SELECT count(*) FROM pg_stat_activity WHERE datname = 'tianshuipy';

-- 查看所有连接
SELECT * FROM pg_stat_activity WHERE datname = 'tianshuipy';

-- 终止所有连接（需要时）
SELECT pg_terminate_backend(pid) 
FROM pg_stat_activity 
WHERE datname = 'tianshuipy' AND pid <> pg_backend_pid();
```

## 📦 数据备份和恢复

### 备份数据库

```bash
# === 使用 Django 备份（JSON 格式）===
python manage.py dumpdata \
    --settings=tianshuipy.settings_postgresql \
    --output=backup_$(date +%Y%m%d_%H%M%S).json

# === 使用 pg_dump 备份（SQL 格式）===
# Windows PowerShell
& "C:\Program Files\PostgreSQL\15\bin\pg_dump.exe" `
    -U postgres `
    -d tianshuipy `
    -F c `
    -f "backup_$(Get-Date -Format 'yyyyMMdd_HHmmss').backup"

# 或纯 SQL 格式
pg_dump -U postgres tianshuipy > backup.sql
```

### 恢复数据库

```bash
# === 从 Django JSON 恢复 ===
python manage.py loaddata backup_20241105_143000.json \
    --settings=tianshuipy.settings_postgresql

# === 从 pg_dump 恢复 ===
# 先删除并重建数据库
psql -U postgres -c "DROP DATABASE IF EXISTS tianshuipy;"
psql -U postgres -c "CREATE DATABASE tianshuipy ENCODING 'UTF8';"

# 恢复数据（自定义格式）
pg_restore -U postgres -d tianshuipy backup.backup

# 恢复数据（SQL 格式）
psql -U postgres -d tianshuipy < backup.sql
```

## 🚀 性能优化命令

### 分析查询性能

```sql
-- 启用查询日志（临时）
SET log_statement = 'all';

-- 分析慢查询
SELECT query, calls, total_time, mean_time
FROM pg_stat_statements
ORDER BY total_time DESC
LIMIT 10;

-- 查看表统计信息
SELECT * FROM pg_stat_user_tables 
WHERE schemaname = 'public';

-- 更新表统计信息
ANALYZE;
VACUUM ANALYZE;
```

### 创建索引

```sql
-- 为常用字段创建索引
CREATE INDEX idx_rs_acquisition_date 
    ON remote_sensing_images(acquisition_date);

CREATE INDEX idx_ei_index_type 
    ON ecological_indices(index_type);

CREATE INDEX idx_pt_status 
    ON processing_tasks(status);

CREATE INDEX idx_oa_created_at 
    ON overlay_analysis_tasks(created_at);

-- 查看索引使用情况
SELECT schemaname, tablename, indexname, idx_scan
FROM pg_stat_user_indexes
WHERE schemaname = 'public'
ORDER BY idx_scan;
```

## 🔄 开发环境切换

### 快速切换配置

```bash
# === 切换到 PostgreSQL ===
# 方式1: 临时切换（推荐开发时）
python manage.py runserver --settings=tianshuipy.settings_postgresql

# 方式2: 环境变量
set DJANGO_SETTINGS_MODULE=tianshuipy.settings_postgresql
python manage.py runserver

# 方式3: 修改 manage.py（永久切换）
# 编辑 manage.py 第6行

# === 切换回 SQLite ===
python manage.py runserver --settings=tianshuipy.settings_dev
```

### 同时维护两个数据库

在 `settings.py` 中配置多数据库：

```python
DATABASES = {
    'default': {
        'ENGINE': 'django.db.backends.postgresql',
        'NAME': 'tianshuipy',
        ...
    },
    'sqlite': {
        'ENGINE': 'django.db.backends.sqlite3',
        'NAME': BASE_DIR / 'db.sqlite3',
    }
}
```

使用时指定数据库：

```python
# 使用 PostgreSQL
User.objects.using('default').all()

# 使用 SQLite
User.objects.using('sqlite').all()
```

## 🛠️ 维护命令

### 定期维护

```sql
-- 清理和优化（建议每周运行）
VACUUM ANALYZE;

-- 重建索引（性能下降时）
REINDEX DATABASE tianshuipy;

-- 清理旧数据（例如：删除6个月前的日志）
DELETE FROM processing_tasks 
WHERE completed_at < NOW() - INTERVAL '6 months';
```

### 数据库清理

```sql
-- 查看膨胀的表
SELECT 
    schemaname, tablename,
    pg_size_pretty(pg_total_relation_size(schemaname||'.'||tablename)) as size,
    n_dead_tup
FROM pg_stat_user_tables
WHERE n_dead_tup > 1000
ORDER BY n_dead_tup DESC;

-- 完全清理
VACUUM FULL;
```

## 💡 实用别名（可选）

在 PowerShell Profile 中添加：

```powershell
# 编辑 Profile
notepad $PROFILE

# 添加以下内容
function dj-pg { python manage.py $args --settings=tianshuipy.settings_postgresql }
function dj-sqlite { python manage.py $args --settings=tianshuipy.settings_dev }
function pg-backup { 
    $date = Get-Date -Format "yyyyMMdd_HHmmss"
    pg_dump -U postgres tianshuipy > "backup_$date.sql"
}

# 使用示例
dj-pg runserver
dj-pg migrate
pg-backup
```
